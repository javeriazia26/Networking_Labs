# VLAN Network with Inter-VLAN Routing

## Overview

This project demonstrates the configuration of a **VLAN-based network** using Cisco Packet Tracer.

The network is divided into three logical networks using VLANs:

* **VLAN 10 — Students**
* **VLAN 20 — Faculty**
* **VLAN 30 — Administration**

A Cisco switch is used to create and manage the VLANs, while a Cisco router is configured for **Inter-VLAN Routing using Router-on-a-Stick**.

The project also demonstrates VLAN isolation and communication between different VLANs through the router.

---

## Objectives

The main objectives of this project are:

* Create and configure multiple VLANs.
* Assign switch ports to specific VLANs.
* Separate users into different logical networks.
* Understand VLAN-based network segmentation.
* Configure a trunk connection between a switch and router.
* Configure Inter-VLAN Routing using router subinterfaces.
* Assign IP addresses and default gateways.
* Test communication within the same VLAN.
* Test isolation between VLANs.
* Verify communication between VLANs through the router.

---

## Network Topology

The basic topology consists of one Cisco router and one Cisco 2960 switch.

```text
                    Cisco Router
                         |
                    Trunk Link
                         |
                    Cisco 2960
                  /      |       \
                 /       |        \
            VLAN 10   VLAN 20    VLAN 30
            Students   Faculty    Administration
               |         |            |
            3 Devices  3 Devices    3 Devices
```

The router provides Inter-VLAN Routing, allowing devices belonging to different VLANs to communicate through their respective default gateways.

---

## VLAN Configuration

| VLAN ID | VLAN Name      | Purpose                |
| ------- | -------------- | ---------------------- |
| 10      | Students       | Student devices        |
| 20      | Faculty        | Faculty devices        |
| 30      | Administration | Administrative devices |

VLANs create separate **broadcast domains**. A broadcast generated by a device in VLAN 10 remains within VLAN 10 unless a Layer 3 device, such as a router, is configured to route traffic between networks.

# Configuration

## 1. Create the VLANs

The VLANs were created on the Cisco switch.

```text
Switch> enable
Switch# configure terminal

Switch(config)# vlan 10
Switch(config-vlan)# name Students
Switch(config-vlan)# exit

Switch(config)# vlan 20
Switch(config-vlan)# name Faculty
Switch(config-vlan)# exit

Switch(config)# vlan 30
Switch(config-vlan)# name Administration
Switch(config-vlan)# exit
```

The VLAN configuration can be verified using:

```text
Switch# show vlan brief
```

---

## 2. Assign Switch Ports

The switch ports were assigned to their respective VLANs.

### VLAN 10 — Students

```text
Switch# configure terminal
Switch(config)# interface range fa0/1-3
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit
```

### VLAN 20 — Faculty

```text
Switch(config)# interface range fa0/4-6
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
Switch(config-if-range)# exit
```

### VLAN 30 — Administration

```text
Switch(config)# interface range fa0/7-9
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 30
Switch(config-if-range)# exit
```

The assignments can be checked with:

```text
Switch# show vlan brief
```

---

## 3. Configure the Trunk Port

The switch port connected to the router was configured as a trunk.

In this project, **FastEthernet 0/24** was used for the router connection.

```text
Switch(config)# interface fa0/24
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit
```

The trunk allows traffic from multiple VLANs to travel between the switch and router over a single physical connection.

---

# Router Configuration

## 4. Enable the Router Interface

The router's physical interface was enabled.

```text
Router> enable
Router# configure terminal

Router(config)# interface gigabitEthernet 0/0
Router(config-if)# no shutdown
Router(config-if)# exit
```

---

## 5. Configure Router Subinterfaces

Router subinterfaces were created for each VLAN.

This configuration is known as **Router-on-a-Stick**.

### VLAN 10 — Students

```text
Router(config)# interface gigabitEthernet 0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit
```

### VLAN 20 — Faculty

```text
Router(config)# interface gigabitEthernet 0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit
```

### VLAN 30 — Administration

```text
Router(config)# interface gigabitEthernet 0/0.30
Router(config-subif)# encapsulation dot1Q 30
Router(config-subif)# ip address 192.168.30.1 255.255.255.0
Router(config-subif)# exit
```

The router configuration can be checked using:

```text
Router# show ip interface brief
```

# Testing

## Test 1 — Same VLAN Communication

Devices belonging to the same VLAN should be able to communicate directly through the switch.

For example:

```text
PC 1 → PC 2
```

Both devices are in VLAN 10, so communication should succeed.

---

## Test 2 — VLAN Isolation

Before configuring Inter-VLAN Routing, devices in different VLANs could not communicate.

For example:

```text
VLAN 10 → VLAN 20
VLAN 10 → VLAN 30
VLAN 20 → VLAN 30
```

These communications failed because a Layer 2 switch does not route traffic between different VLANs.

This confirmed that the VLAN segmentation was working correctly.

---

## Test 3 — Inter-VLAN Communication

After configuring the router and Router-on-a-Stick, devices from different VLANs were able to communicate.

For example:

```text
Student PC
192.168.10.10
       |
       ↓
192.168.10.1
Router
192.168.20.1
       |
       ↓
Faculty PC
192.168.20.10
```

A test can be performed using:

```text
ping 192.168.20.10
```

and:

```text
ping 192.168.30.10
```

Successful replies confirm that Inter-VLAN Routing is functioning.

---

## Understanding the Initial Packet Loss

During the first ping test, approximately **25% packet loss** was observed.

The subsequent ping was successful with **0% packet loss**.

This can occur because the network devices need to perform **ARP resolution** before normal communication begins. Once the required MAC address information has been learned, subsequent packets can be forwarded normally.

# Key Concepts Learned

### VLAN

A **Virtual Local Area Network (VLAN)** logically divides a physical network into separate networks or broadcast domains.

### Access Port

An access port normally carries traffic for a single VLAN and is used to connect end devices such as PCs and printers.

### Trunk Port

A trunk port carries traffic for multiple VLANs between networking devices.

### Broadcast Domain

Each VLAN represents a separate broadcast domain. Broadcast traffic from one VLAN does not normally reach other VLANs.

### Inter-VLAN Routing

Inter-VLAN Routing allows devices in different VLANs to communicate through a Layer 3 device such as a router.

### Router-on-a-Stick

Router-on-a-Stick uses a single physical router interface with multiple subinterfaces to route traffic between multiple VLANs.

### Default Gateway

The router's subinterface IP address acts as the default gateway for devices in its corresponding VLAN.

For example:

```text
VLAN 10 → 192.168.10.1
VLAN 20 → 192.168.20.1
VLAN 30 → 192.168.30.1
```
